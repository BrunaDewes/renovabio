# Contextos

Esta pasta contem providers e estados globais do aplicativo.

## Arquivo atual

- `auth-context.tsx`: controla autenticacao, usuario logado, token e funcoes de login/logout usadas pelas telas.

## Uso

Coloque aqui estados que precisam ser acessados por varias telas. Estados locais de uma tela devem continuar dentro do proprio componente.
