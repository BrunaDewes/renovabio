# Utilitarios

Esta pasta contem funcoes e dados auxiliares compartilhados entre telas.

## Arquivos

- `api.ts`: URL base da API, montagem de URLs de imagens remotas, criacao de `FormData` para imagem e headers de autenticacao.
- `desafios.ts`: dados ou helpers ligados ao fluxo de desafios.
- `receitas.ts`: dados ou helpers ligados ao fluxo de receitas.

## Uso

Coloque aqui funcoes puras, adaptadores de API e dados auxiliares que nao dependem diretamente da interface. Componentes visuais devem ficar em `components`.
