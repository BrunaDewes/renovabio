# Hooks

Esta pasta guarda hooks reutilizaveis do app.

## Arquivos

- `use-color-scheme.ts`: identifica o esquema de cores do dispositivo.
- `use-color-scheme.web.ts`: versao especifica para web.
- `use-theme-color.ts`: resolve cores a partir do tema atual.

## Uso

Hooks devem encapsular comportamento reutilizavel de React ou React Native. Evite misturar renderizacao de tela dentro desta pasta.
