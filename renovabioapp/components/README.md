# Componentes

Esta pasta contem componentes reutilizaveis usados pelas telas do app.

## Componentes

- `avatar.tsx`: exibicao de avatar/foto de usuario.
- `password-input.tsx`: campo de senha com comportamento visual proprio.
- `themed-text.tsx` e `themed-view.tsx`: wrappers com suporte ao tema.
- `external-link.tsx`: link externo com tratamento adequado no Expo.
- `haptic-tab.tsx`: tab com feedback haptico.
- `hello-wave.tsx`: componente visual simples.
- `parallax-scroll-view.tsx`: scroll com efeito de parallax.
- `ui`: componentes visuais de apoio e compatibilidade.

## Padrao

Componentes desta pasta sao genericos o suficiente para uso em mais de uma tela. Logica especifica de uma tela permanece em `app`.
