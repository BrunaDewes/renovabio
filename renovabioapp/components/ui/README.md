# Componentes de UI

Esta pasta contem componentes visuais menores e adaptacoes por plataforma.

## Arquivos

- `collapsible.tsx`: componente expansivel/recolhivel.
- `icon-symbol.tsx`: icones simbolicos compartilhados.
- `icon-symbol.ios.tsx`: versao especifica para iOS quando necessario.

## Uso

Use estes componentes como blocos de apoio para telas e componentes maiores. Evite colocar chamadas de API ou regras de negocio aqui.
